Google Cloud Console Setup:

Go to Google Cloud Console

  1. Select your project
  2. Go to "APIs & Services" → "Credentials"
  3. Click on your OAuth 2.0 Client ID
  4. In "Authorized redirect URIs", add EXACTLY:
    http://127.0.0.1:8000/social/google/login/callback/
  5. Save changes
  6. Wait 2-3 minutes for changes to propagate

Required APIs:

Make sure these APIs are enabled in Google Cloud Console:

  • Google+ API (or People API)
  • OAuth 2.0 API

Common Errors:

  • redirect_uri_mismatch: Wrong redirect URI in Google Console
  • invalid_client: Wrong Client ID/Secret
  • access_denied: Required APIs not enabled
  • internal_server_error: Django configuration issue
